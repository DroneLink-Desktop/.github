DroneLink is a drone mission planning application for Windows that helps pilots design, review, and manage repeatable automated flights.

## Common Questions

| Question | Answer |
|---|---|
| Is DroneLink free? | DroneLink does not offer a fully free plan for creating and flying missions. You can test whether the flight environment recognizes compatible hardware before purchasing, while continued mission use requires an appropriate plan. |
| Which versions of Windows are supported? | Compatibility can change between releases. Use a currently maintained Windows version and confirm the latest system requirements before installation. |
| How does DroneLink pricing work? | Hobbyist access is offered through one-time plan purchases, while professional use is covered by subscription plans. Features and terms vary by tier, so review the current plan comparison before choosing. |
| How do I get DroneLink connected to a drone? | Confirm that the aircraft, controller, and required connection method are supported, close any competing flight-control software, grant the requested permissions, and check the flight dashboard before starting a mission. |

## Start Your First Mission

Sign in or create an account, open a new mission plan, and define the route and capture actions needed for the job. Review the planned path and settings before saving the mission, then confirm that the selected aircraft and controller setup is supported before moving to live flight preparation.

## A Practical First-Flight Tip

> **Tip:** Preview the complete mission and verify aircraft, controller, and connection compatibility before using the plan in the field.

## Security and Data Handling

DroneLink uses account-based access for planning and mission features. Because a workflow can include cloud-backed account data and operational information used during flight preparation, review the available privacy and sharing controls before adding sensitive mission details, and share plans only with intended collaborators.
